# Bahrain Social

An interactive 3D map of Bahrain that people can explore and add to. Fly over the whole kingdom, find places near you, and see what others have left on the map: tips, notes, questions and events.

> Prototype. It runs as a single web page. It is not yet publicly hosted and has no sign-up of its own.

## Features

**A 3D Bahrain built from real map data**
- 191,495 buildings, 105,317 road segments, the coastline, reclaimed islands, the Hawar Islands and the King Fahd Causeway
- Building heights from mapped values where they exist, otherwise satellite-derived estimates
- Towers, villas with tiled roofs, mosques with domes and minarets, warehouses, walled compounds, palms and street lamps
- Hand-built landmarks: Bahrain World Trade Center, Al Fateh Grand Mosque, Bahrain Financial Harbour
- A 24-hour clock with sunrise, midday, golden hour and night, with lit windows and street lights
- 3D cars whose numbers follow a simulated daily rush-hour pattern

**Explore**
- 4,341 places in 24 groups: food by cuisine, pharmacies, hospitals, petrol stations, banks, supermarkets, beaches, parks, historic sites, museums, cinemas, hotels and malls
- Search by road, area, place name or pasted coordinates
- Hearts and short tips on every place

**Social**
- Notes pinned to a spot, which expire after a day or a week
- Questions that people nearby can answer
- Events with a date, time and "I'm going"
- Tag yourself on the map with a nickname and favourite food

**Privacy and safety**
- No addresses are stored; every tag and post is placed to the nearest 100 m
- Links are removed from posts
- Anything reported by three people is hidden, and the page owner can remove any item

## Getting started

Requirements: Node.js 18 or newer.

```bash
npm install
node tools/build.mjs
```

Open `bahrain.html` in a browser with WebGL 2 enabled. In this standalone file, tags and posts are saved in your browser only.

### Controls

| Action | How |
|---|---|
| Move | Drag |
| Zoom | Scroll or pinch |
| Turn and tilt | Right-drag, Ctrl-drag, or two fingers |
| Fly | W A S D, with Q and E to turn |

## Rebuilding the data

The built assets in `data/` are enough to run the page. To regenerate them you need Python 3 with `pillow`, `numpy`, `scipy`, `duckdb`, `pandas`, `pyarrow`, `shapely` and `tifffile`.

```bash
python tools/fetch_data.py <raw_dir> <tile_cache_dir>     # imagery and elevation tiles
python tools/process_data.py <raw_dir> data               # texture, water mask, heightmap
python tools/fetch_vectors.py <vector_dir> data/bounds.json   # buildings, roads, places
python tools/pack_city.py <vector_dir> <raw_dir> data <ghsl_dir>
node tools/build.mjs
```

Some inputs used by `pack_city.py` (per-building heights, bridge flags, governorate boundaries, the GHSL height raster) were downloaded by hand and are not yet scripted.

## Limitations

- Surfaces are generated by rule. A building is in the right place with the right outline, but its colour, windows and roof are not the real ones.
- Ground imagery is 10 m per pixel, so there is no real street-level detail.
- Most footprints are machine-traced, so some houses are merged or missing.
- Traffic is a simulation, not a live feed.
- Needs a device with working WebGL 2; otherwise a simplified flat view is shown.
